# Ebook Golang 📘

## Sobre o ebook 📖
&nbsp;&nbsp;&nbsp; Este ebook é fruto do meu projeto extensionista desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS). O projeto tinha como requisito atender uma das [ODS](https://brasil.un.org/pt-br/sdgs) da ONU e utilizar a tecnologia para contribuir com a sociedade.

&nbsp;&nbsp;&nbsp; Meu objetivo foi contribuir com a comunidade de desenvolvedores, em especial com a comunidade Go, que ainda não é tão grande no Brasil. Esforcei-me para explicar os conceitos de forma simples e direta, pois acredito que essa abordagem seja a mais eficaz. Além disso, incluí imagens com exemplos para tornar o conteúdo o mais didático possível.

## Sobre o desenvolvimento do projeto ⚙️
&nbsp;&nbsp;&nbsp; O projeto poderia ser realizado em grupos de até três pessoas, mas, devido às minhas dificuldades de comunicação e interação social, optei por fazê-lo sozinho. Inicialmente, estava incerto sobre o que criar, justamente por conta das minhas limitações, mas após avaliar as opções, decidi que um ebook seria a melhor escolha.

&nbsp;&nbsp;&nbsp; Na época, estava aprendendo a linguagem Go, e o desenvolvimento deste ebook acelerou significativamente meu aprendizado, pois precisei assimilar rapidamente o conteúdo para incluir tudo o que considerava essencial. Tive um prazo de apenas 13 dias para concluir o projeto. Talvez não tenha saído exatamente como eu imaginava, mas me dediquei intensamente para entregar o melhor resultado possível.
